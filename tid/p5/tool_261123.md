# PEG与正则

## PEG的设计思想

原论文基于组合子逻辑，设计了一种新的自动机，相比正则引入了递归能力，同时用确定性代替了正则中比较模糊的回溯语义，实现O(n)的解析速度。基于此论文，lua/janet等语言又增加了捕获能力，更使PEG成为和YACC成为各有千秋的解析生成工具。

1. 确定性

每个PEG的完整表达式一旦匹配就不会回吐，从而具备了seq x n的时间性。但不回吐又削弱了表达能力，因此允许单个表达式内的子句在匹配失败后按序下一种模式，注意这里的子模式是有序的，举例

```
a / ab (论文写法)或 a + ab(lpeg实现)
```

面对ab字符串时，一旦a子项匹配，整个表达式就结束了，不会尝试ab子项。避免出现正则中的到底left first还是longest first的歧义性。

确定性还有其它表述：永远贪婪，不过这更像是一种外显的表征，真正的内核还是确定性匹配占用。

2. 右递归

这点和确定性存在关联，右递归意味着匹配能走下去，举例

```
S : a S
```

至少要消耗1个a，或者不用这个模式，保证匹配有确定性结果。但如果把S写在左边就会无限展开。
